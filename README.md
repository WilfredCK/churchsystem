# EcclesiaSync Church Management — Enhanced Interactive Simulation

## Run it
1. Extract this ZIP.
2. Open `index.html` in a modern browser, or use VS Code Live Server.
3. Sign in with the prefilled demo values or any non-empty credentials.

## Enhanced modules
- Member records include unique member IDs, gender and age, with gender/age filters.
- Weekly Jumuiya register captures meeting date, group, venue, male/female/children attendance and offering; supports date search, create/edit/delete and CSV export.
- Service tracker has a service dropdown and date-level male/female/children attendance, fund, cash, pledges and total impact.
- Finance chart is initialized on the finance page; demo chart values are illustrative.
- Member offerings supports member, date, service, fund, cash/pledge, cash/bank/mobile channel, totals, filters and export.
- Expenses support budget item, account, payment channel and bank/mobile-money channel.
- Budget cards open a spending-history view with chart and available approval/channel fields.
- Fund cards show giver-level contributions, contact, service, cash/pledge and channel, with CSV export.
- Inventory shows good vs needs-attention units and editable records.
- Church profile includes a leadership and committee directory.

## Important limitations
This is a front-end simulation using sample data in browser memory; reload resets changes. Login is not real authentication and charts/fonts use CDNs. Do not enter real member or financial data. Production deployment needs a secure backend, persistent database, access control, audit logs, backups and privacy/security review.
